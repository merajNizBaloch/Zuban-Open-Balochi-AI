# Zubán Roadmap

## v0.1 — Foundation
- Web platform and public product shell
- Chat and translation model-adapter interface
- Dictionary workspace
- Speech, voice and OCR labs
- Research, technology and dataset registry
- GitHub-native contribution workflow
- Provenance and dialect metadata conventions

## v0.2 — Data
- Import and audit reusable open Balochi datasets
- Establish Zubán Corpus schema
- Establish Zubán Lexicon schema
- Community translation verification
- Voice contribution workflow
- Dialect/script tagging guidelines

## v0.3 — Models
- Baseline translation evaluation
- Balochi embeddings/search baseline
- Speech-to-text baseline
- Text-to-speech baseline
- OCR baseline
- Public model cards

## v0.4 — Zubán Bench
- Translation benchmark
- ASR benchmark
- OCR benchmark
- POS/NER evaluation
- Retrieval/embedding benchmark
- Reproducible leaderboard

## v1.0
A stable, free and open Balochi AI platform backed by documented datasets, independently reproducible evaluations and community governance.
