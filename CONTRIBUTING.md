# Contributing to Zubán

Zubán welcomes Balochi speakers, linguists, researchers, developers, writers, students and institutions.

## Ways to contribute

- Correct Balochi text or translations.
- Add dialect/script metadata.
- Contribute properly licensed text or speech data.
- Review dictionary entries.
- Test models and report failure cases.
- Improve code, accessibility and documentation.
- Propose or reproduce research.

## Data contribution rules

Every dataset contribution should include as much provenance as possible:

- source
- author/collector when relevant
- license or permission status
- dialect/variety when known
- script
- collection method
- whether a human reviewer verified it

Do **not** upload copyrighted books, private recordings, scraped personal conversations, or third-party datasets without permission.

## Development

1. Fork the repository.
2. Create a focused branch.
3. Keep changes small and documented.
4. Run `npm run build` before opening a pull request.
5. Explain what changed and how it was tested.

## Linguistic uncertainty

Balochi is dialectally diverse. Do not silently label one regional form as universally correct. When uncertain, mark the variety, source, or confidence.

## Community

Be precise, respectful and collaborative. Disagreement about spelling, dialect or analysis should be documented rather than personalized.
